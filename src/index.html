How to read this

  • Each row is one provider on one frozen test set, scored only from its run log. The run date is shown on every row.
  • Search: a query passes when the expected article URL is in the top 10 results (or a same-outlet result published within 72 h). Browser: the provider loads that same article URL and passes when the page text contains the headline.
  • below minimum (n=X) means that week's set has fewer than 25 questions. Treat those numbers as early and directional, not a ranking.
  • rate-limited (free tier) counts HTTP 429 replies from a provider's free plan. They are shown apart from quality fails and left out of the success rate.
  • Not run yet: no collector or key for that provider yet. Costs are list prices for the named tier; free tiers never lower a cost, and "n/a" means the price was not on the vendor's page.
  • Rankings are never paid. Sponsors only appear in labelled slots (sponsors, disclosures).
